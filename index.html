Connect this device to GitHub — once per phone or computer.

Your key stays on this device and is sent only to GitHub. This page can't contact any other website, and it never sees the Facebook / Instagram login — that stays locked inside your private GitHub repo.

Connect to GitHub

How to make the GitHub key

  1. github.com → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Name: posts dashboard · Expiration: 90 days
  3. Repository access: Only select repositories → believer-solar-posts
  4. Repository permissions: Contents → Read and write and Actions → Read and write. Leave everything else as No access — especially Workflows.
  5. Generate, copy, paste above. Lost a phone? Delete the token on GitHub — every device is locked out at once.
